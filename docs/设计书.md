## 1. 产品概述

### 1.1 一句话定义

一款**完全离线、数据不出设备**的手机记账本：用二次元手游的**像素点阵 UI**，配以静流 / 黄泉 / 绯雪一类角色所代表的**清冷**气质，覆盖记账、存钱、余额、饼图对照与花销分析。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| 本地优先 | 无账号、无云同步、无埋点；数据只写本机 |
| 基础够用 | 先做日用闭环，不做投资、分期、联机账本 |
| 像素 + 清冷 | 点阵界面结构保留；色彩与氛围走冷、淡、静，**不做暗黑地牢 / 暖金冒险风** |
| 单手友好 | 底部导航 + 大号数字键盘，竖屏优先 |

### 1.3 目标用户

- 个人日常记账、想看清「钱花哪了」  
- 偏好二游清冷审美，不喜欢传统理财 App 的表格感  
- 重视隐私、账单不上云  

### 1.4 非目标（首版不做）

- 云同步 / 多端登录 / 社交分享  
- OCR 扫票、银行自动导入  
- 订阅会员、推送营销  
- 多币种汇率、股票基金

## 3. 视觉设计：清冷像素风（取代暗黑方案）

### 3.1 风格定义

- **情绪**：冷、静、干净；留白多、装饰少；像霜面上的一行账  
- **结构**：仍用像素描边、点阵图标、方块进度、硬边饼图（二游工具感）  
- **光线**：浅冷底 + 薄雾渐变，局部冰蓝 / 冷紫 / 淡绯点缀，**整体高明度或中高明度**，避免大面积纯黑  
- **字体**：标题可用细像素字；正文优先清晰可读的冷色无衬线  
- **动效**：低帧、克制（霜晶闪一下、面板淡入），不做金币蹦跳、爆炸庆祝  

### 3.2 色彩令牌（清冷）

| Token | 色值 | 用途 |
|-------|------|------|
| `--bg-base` | `#E8EEF4` | 主背景：霜雾灰蓝 |
| `--bg-panel` | `#F7FAFC` | 面板：近白冷瓷 |
| `--bg-mist` | `#D4DCE8` → `#EDE4EC` | 背景薄雾渐变（蓝灰 → 极淡冷紫） |
| `--border` | `#9AA8B8` | 像素描边（冷灰蓝） |
| `--text` | `#2C3A4A` | 主文字（墨青，非纯黑） |
| `--text-dim` | `#6B7C8F` | 次要文字 |
| `--accent-ice` | `#7EB6D4` | 主强调：静流向冰蓝 |
| `--accent-violet` | `#8B7BA8` | 辅强调：黄泉向冷紫（选中 / 图表） |
| `--accent-rose` | `#C4899A` | 点缀：绯雪向冷绯（支出强调、达成） |
| `--expense` | `#B85C6E` | 支出（冷绯红，非警报红） |
| `--income` | `#5A9A8A` | 收入（冷青碧） |
| `--balance` | `#4A6B8A` | 余额数字 |
| `--bar-empty` | `#D0D8E2` | 进度条底 |
| `--bar-fill` | `#7EB6D4` | 进度条填充 |
| `--warning` | `#A67C52` | 负余额等提示（冷褐，少用） |

饼图分类色：在冰蓝、冷紫、冷绯、霜青、银灰等**低饱和冷色**中取 8–12 色，避免高饱和霓虹。

### 4.2 原 P1 功能细则（已锁定进首版）

#### 导出备份

- 入口：设置 →「导出账册」  
- 格式：JSON（完整可再导入预留）+ CSV（表格可读）  
- 范围：分类、流水、霜匣、预算、设置（不含系统无关缓存）  
- 保存：系统文件选择器 / 分享到本地存储；**不上传**  

#### 搜索与筛选

- 霜页顶栏：搜索框（匹配备注、金额文本）  
- 筛选芯片：全部 / 支出 / 收入；分类多选；当前月或自定义月  
- 无结果：空态「未找到相关霜页」  

#### 月度收支总览

- 位于清点 · 对照顶部或独立卡片  
- 双条对照：本月收入条 / 本月支出条（同尺度）+ 结余数字  
- 与饼图、花销分析共用时间筛选  

#### 简单月预算

- 设置或清点内：「启用本月预算」开关（默认关）  
- 可设**总支出预算**；P0 不做复杂多分类强制，允许可选 1～N 个分类预算  
- 花销笺展示：已用 / 预算 / 剩余；超支用冷绯提示，不弹骚扰通知  
- 数据表：`budgets`（month、scope=total|category、category_id?、amount）  

#### 删除二次确认

- 文案短冷：「确认删除此记录？」「霜匣内金额将退回可用余额」  
- 按钮：取消 / 确认删除（危险色冷绯）

## 5. 花销分析（新增模块详设）

> 饼图回答「结构」；花销分析回答「趋势、对比、异常、建议线索」。

### 5.1 入口

- Tab **清点** 内分两个子页：`对照`（饼图）| `分析`（花销笺）  
- 或首页余额下提供「本月花销」摘要卡，点进分析  

### 5.2 分析内容（首版必做）

| 能力 | 展示 | 计算要点 |
|------|------|----------|
| 本月花销总额 | 大号数字 + 较上月变化％ | `(本月支出 - 上月支出) / 上月支出`；上月为 0 则显示「—」 |
| 日均花销 | 本月支出 ÷ 已过天数 | 按自然月已过日 |
| 分类排行 | Top 3～5 冷色条 | 同饼图数据源 |
| 收支结余 | 本月收入 − 本月支出 | 负值用冷绯字 |
| 近 6 个月支出趋势 | 极简像素折线 / 柱 | 按月聚合支出 |
| **月度收支总览条** | 收入条 vs 支出条 + 结余 | 与时间筛选联动 |
| **与预算对照** | 已用／预算／剩余 | 仅当启用月预算时显示 |
| **环比异常提示** | 一条冷色短句 | 分类增幅 > 30% 且差额 ≥ 阈值 |

### 5.3 分析内容（后续可选）

| 能力 | 说明 |
|------|------|
| 工作日 vs 周末 | 简单两列均销对比 |

### 5.4 交互与空态

- 时间：本月｜上月｜近 90 天  
- 无数据：薄雾底 + 一句「尚无花销可析」  
- 全部计算本地完成，无网络  

### 5.5 与饼图分工

| | 饼图对照 | 花销分析 |
|--|----------|----------|
| 核心问题 | 钱按类怎么分 | 花得是否比以前多、结余如何、往哪飘 |
| 主视觉 | 硬边饼图 | 数字摘要 + 条形榜 + 月趋势 |
| 共用 | 同一套 transactions 与分类 |

## 7. 关键页面要点

### 7.1 首页 · 霜衡

1. 顶栏：应用名 + 设置  
2. 余额面板：可用余额；副行本月支出 / 收入；可选「净资产」  
3. **本月花销摘要**：总额 + 较上月箭头；点击进花销分析  
4. 快捷：`记支出` `记收入` `积一笔`  
5. 近 5 笔霜页  

### 7.2 记一笔

类型、金额（像素键盘）、分类、日期、备注；主按钮「记入」。  
校验用 FrostDialog 短句提示。

### 7.3 霜页 · 流水

按日分组；月份选择；**搜索备注**；筛选全部/支出/收入与分类；编辑/删除（**删前二次确认**）。

### 7.4 清点 · 对照 + 分析

见 §5；顶部含**月度收支总览条**；饼图中心为总支出或选中分类金额；分析页含预算对照（若已开启）。

### 7.5 霜匣 · 存钱

目标进度（冰蓝填充）；转入/转出；满额时一次轻量霜晶反馈（非狂欢）；删除霜匣二次确认并退回余额。

### 7.6 设置

初始余额、**月预算开关与金额**、**导出 JSON/CSV**、清空数据（双重确认）、本地存储说明、关于。

## 8. 数据与计算（保持本地）

### 8.1 存储

SQLite（Flutter `sqflite` 等）；无网络权限。

### 8.2 核心公式

```
可用余额 = 初始余额 + Σ收入 − Σ支出 − Σ存入霜匣 + Σ从匣取出
净资产   = 可用余额 + Σ霜匣余额
```

花销分析只统计 `type = expense` 的 transactions（存钱划转不计入「花销」）。

### 8.3 表（逻辑）

- `settings`：initial_balance  
- `categories`：name / type / icon_key  
- `transactions`：type / amount / category_id / note / occurred_at  
- `piggy_banks`：name / target / current  
- `piggy_transfers`：in/out 明细（可选）  
- `budgets`（P1）：month / category_id? / amount  

### 8.4 边界

| 场景 | 规则 |
|------|------|
| 金额 | 0.01～9,999,999.99 |
| 余额为负 | 允许，冷绯提示 |
| 存入 > 可用 | 禁止 |
| 删除霜匣 | 余额退回可用 |
| 时区 | 设备本地，自然日 |
